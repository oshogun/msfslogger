# T-003 fix round 1 — Finding 1 (blocking): /trip/:id horizontal overflow at 800px

## The fix

`.legs-section`'s `<table>` in `client/src/pages/TripDetail.tsx` had no
horizontal-scroll wrapper, so at ≤900px the 8-column table plus the
in-flow `.sidebar-toggle` (40px, not absolutely positioned) blew out
`document.documentElement.scrollWidth` past the viewport.

Chosen fix (the Reviewer's first-listed direction, not the toggle-hiding
shortcut): wrapped the legs `<table>` in a `div.legs-table-wrap` with
`overflow-x: auto`, so the table scrolls internally instead of the
document going wide — same idea as the existing `.app-main { min-width: 0 }`
rule, contain the overflow at the smallest scope that can absorb it.

- `client/src/pages/TripDetail.tsx`: added `<div className="legs-table-wrap">`
  around the existing `<table>...</table>` in the legs section (no other
  change to that markup).
- `client/src/index.css`: added `.legs-table-wrap { overflow-x: auto; }`
  right after the existing `.legs-section` rule (~L366).

Did not touch `.sidebar-toggle`, `.app-body`, `.sidebar` rules, or
`App.tsx` — the toggle still renders and behaves exactly as before; only
the legs table's own overflow behavior changed.
