## Non-blocking follow-ups

1. **Repeated trip header rows.** `Prefiles.tsx:344-352` emits a group row per leg,
   so a 21-leg trip prints `Circumnavegação` 21 times (seen in the screenshot).
   §7.4 only requires each row show its trip, so this conforms — but collapsing
   consecutive same-trip headers would read better.
2. **Dead reorder arrows.** Reusing `GhostLegRow` unmodified brings its ↑/↓
   buttons, which `Prefiles.tsx:356-358` wires to `onMove={() => {}}` with
   `canMoveUp/Down={false}` — permanently disabled controls on a page where §7.4
   says reorder is deliberately absent. Harmless and a forced consequence of §7.5's
   "PlannedLegRows.tsx needs no change"; worth an opt-out prop if it ever itches.
3. **`linkableFlights` is cached across rows** and only invalidated after a
   successful link, so a flight linked in another tab stays in the dropdown until
   reload. Same behaviour TripDetail already has; not a regression.
