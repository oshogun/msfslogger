### 5. Rounding character-identical to `src/flightManager.ts:463`

`src/plannedLegClose.ts`'s `handCloseDeviationNm()` uses, verbatim:

```ts
Math.round(
  haversineNm(flight.arrival_lat, flight.arrival_lon, leg.destination_lat, leg.destination_lon) * 10
) / 10
```

— the same expression, character for character, as
`Math.round(deviationNm * 10) / 10` at `src/flightManager.ts:463`.

The inspector's "rounding boundary" row (output above) uses a due-north offset
found by binary search (`destination_lat = 0.0024983152722295506`,
`destination_lon = 0`, `arrival_lat = arrival_lon = 0`) so that the raw
haversine distance is the double nearest 0.15 nm
(`0.14999999999999999445`), a value at which the frozen rounding and the
`toFixed`-based alternative the design explicitly rules out **actually
diverge**: `Math.round(raw * 10) / 10` gives `0.2` (because `raw * 10`
rounds up to exactly `1.5` in floating point, and `Math.round` rounds halves
away from zero), while `Number(raw.toFixed(1))` gives `0.1` (because
`toFixed` rounds the original, still-just-under-0.15 double directly). The
report shows both values plus `handCloseDeviationNm()`'s and
`decideHandClose()`'s actual output, `0.2` — the frozen expression, not the
look-alike.

The search that found this boundary (not part of the shipped inspector, run
separately to construct the fixture):

```
node -e "
function haversineNm(lat1, lon1, lat2, lon2) {
  const R = 3440.065;
  const dLat = ((lat2 - lat1) * Math.PI) / 180;
  const dLon = ((lon2 - lon1) * Math.PI) / 180;
  const a = Math.sin(dLat/2)**2 + Math.cos(lat1*Math.PI/180)*Math.cos(lat2*Math.PI/180)*Math.sin(dLon/2)**2;
  return R*2*Math.atan2(Math.sqrt(a), Math.sqrt(1-a));
}
function findLatForDistance(target){let lo=0,hi=10;for(let i=0;i<200;i++){const mid=(lo+hi)/2;const d=haversineNm(0,0,mid,0);if(d<target)lo=mid;else hi=mid;}return (lo+hi)/2;}
const lat2 = findLatForDistance(0.15);
const raw = haversineNm(0,0,lat2,0);
console.log('lat2', lat2.toPrecision(20));
console.log('raw', raw.toPrecision(20));
console.log('Math.round(raw*10)/10 =', Math.round(raw*10)/10);
console.log('Number(raw.toFixed(1)) =', Number(raw.toFixed(1)));
"
```
